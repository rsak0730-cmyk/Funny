Sreya's Birthday Surprise
==========================

Kivabe khulbe:
1. Zip file ta unzip (extract) koro.
2. index.html file ta phone ba computer er browser (Chrome) e kholo.

Notes:
- Midnight (12:00 AM, 29 October, IST) er age shudhu countdown dekhabe. Ager moddhe dekhte chaile
  ghumonto teddy ke 5 bar tap koro.
- Bangla font ar google fonts er jonno internet lagbe. Internet na thakleo kaj korbe, shudhu font alada dekhate pare.
- Lekha bodlate chaile index.html ta text editor e khule script er CFG part e wishes, from, target time bodlao.
